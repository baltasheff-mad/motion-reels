# Первый ролик в Motion Reels

Это адаптация [пайплайна @saint4ai](https://github.com/saint4ai/reels-pipline-automotaj).
Условия и авторство сохранены в [LICENSE](LICENSE) и [NOTICE](NOTICE).

## Подготовка

Открой папку репозитория в Codex или Claude Code. Попроси агента установить проект по
[SETUP.md](SETUP.md). Для Codex используется `scripts/bootstrap-portable.sh --codex`.
Для установки отправь агенту:

```text
Склонируй https://github.com/baltasheff-mad/motion-reels и подготовь проект
по SETUP.md для Codex. Прочитай AGENTS.md и CONTEXT.md.
```

После установки агент проверяет студию по технической инструкции.

## Новый ролик

Создай отдельную папку для каждого исходника на своём компьютере и дай агенту точный путь.
Не используй название прошлого проекта для нового видео.

Пример сообщения, где путь нужно заменить на реальный:

```text
Новый проект: lesson-02. Исходник: /полный/путь/к/lesson-02.mp4.
Формат: YouTube 16:9. Это готовый видеоурок со скринкастом.
Сохрани структуру и порядок объяснения. Убери лишние паузы, добавь
читаемые подписи к действиям на экране. Стиль выберем по референсам.
Сначала предложи карту монтажа, затем покажи листы кадров перед рендером.
```

Агент использует `scripts/new-video.sh <id> <reels|youtube> <точный-путь>`.
У каждого ролика будут свои данные в `videos/<id>/`, код в `studio/src/videos/<id>/`
и запись в `studio/public/projects/<id>/`.

## Оформление

Можно выбрать исходные стили из [каталога](patterns/README.md) или дать свой референс.
Цвета и шрифт фиксируются в `videos/<id>/BRIEF.md` и `CONCEPT.md`.
Стили из примеров показывают возможности исходной библиотеки.

## Правки

Попроси листы кадров с номерами. Пиши конкретно: «К007: подпись крупнее»,
«на 12 секунде покажи кнопку, на которую я нажимаю».
После правок агент повторяет проверку. Команда «кадры приняты, рендерь» запускает финальный рендер.

Готовый ролик: `videos/<id>/renders/final.mp4`.

## Продолжение проекта

В новом чате назови ID ролика и попроси прочитать его бриф и карту монтажа.
Если это другой исходник, начни с нового ID и точного пути к файлу.
