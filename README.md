# Motion Reels

Автоматизированный монтаж видео для Reels, Shorts и TikTok с помощью ИИ.
Субтитры, анимации, переходы и визуальные эффекты с использованием Codex, Remotion и FFmpeg.

Основа: [Reels Pipeline Automontaj](https://github.com/saint4ai/reels-pipline-automotaj),
автор исходного метода и реализации: onAI Academy, [@saint4ai](https://instagram.com/saint4ai).
Изменения этой версии описаны в [ADAPTATION.md](docs/ADAPTATION.md).

## Начать

Репозиторий: [baltasheff-mad/motion-reels](https://github.com/baltasheff-mad/motion-reels).

Открой Codex и отправь:

```text
Склонируй https://github.com/baltasheff-mad/motion-reels.
Подготовь репозиторий по SETUP.md для работы в Codex.
Прочитай AGENTS.md, CONTEXT.md и knowledge/personal-brand-content-system.md.
После установки помоги начать новый ролик по START.md.
```

[START.md](START.md) объясняет первый запуск, выбор исходника и работу с правками.
[SETUP.md](SETUP.md) содержит техническую установку.

## Что можно собрать

- Рилс 9:16 с записью спикера, субтитрами и графикой.
- Видео 16:9 для YouTube.
- Видеоурок со скринкастом: сохранить порядок объяснения, добавить акценты и убрать лишние паузы по согласованной карте монтажа.

Для готового урока агент сохраняет структуру и текст автора. Продающий хук и CTA добавляются только по запросу.

## Как проходит монтаж

1. Указываешь отдельный ID проекта и точный путь к исходнику.
2. Выбираешь формат и визуальный стиль.
3. Агент составляет карту монтажа и собирает сцены в Remotion.
4. Проверяет типы и размещение текста, показывает листы кадров.
5. После твоего подтверждения рендерит MP4 и проверяет результат.

Новый исходник получает новый ID. Например, `lesson-01` и `lesson-02` хранятся отдельно.
Подробнее: [START.md](START.md).

## Стили

В исходной библиотеке есть канвас, стекло, постер, смена сцен и дополнительные паттерны.
Кадры для выбора: [основные стили](reference/style-previews/styles.jpg),
[дополнительные](reference/style-previews/more-styles.jpg).

Для этой версии можно выбрать собственные цвета, шрифты и референсы в брифе ролика.
Глобального оформления BALTASHEFF пока нет: библиотека сцен сохраняет исходные стили.

## Структура

| Папка | Назначение |
|---|---|
| `studio/` | Remotion, Storybook, компоненты, анимации и рендер |
| `videos/<id>/` | Бриф, сценарий, карта монтажа и готовые файлы ролика |
| `studio/src/videos/<id>/` | Код конкретного ролика |
| `studio/public/projects/<id>/` | Локальные записи, не попадают в Git |
| `knowledge/` | Принципы монтажа и профиль автора |
| `patterns/` | Каталог исходных стилей и приёмов |
| `reference/` | Референсы и разборы |
| `scripts/` | Подготовка проекта и проверки |

Команды студии: [studio/README.md](studio/README.md).

## Проверки

Из `studio/`: `npm run typecheck`, проверка контейнеров `qa-fit.mjs`,
листы кадров `review.mjs`. После рендера проверяются кадры MP4, параметры файла и звук.
Сам рендер этой адаптации пока не проверялся.
